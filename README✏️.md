# 🛒 Varejo Analytics AI: Simulação e Insights

Projeto desenvolvido para demonstrar capacidade de análise de dados, simulação de cenários de mercado e visualização interativa usando **Python** e **Google Colab**.

## 🚀 O que este projeto faz
Este notebook gera automaticamente 10.000 transações de varejo sintéticas, injetando comportamentos reais de mercado (como sazonalidade de Páscoa no Norte e crescimento do setor de Saúde) para criar um dataset realista do zero.

## 📊 Insights Gerados
- **Sazonalidade Regional:** Detecção automática de picos de vendas no 1º trimestre na região Norte.
- **Performance Setorial:** Comparativo de crescimento entre setores (Alimentos vs. Saúde vs. Eletrônicos).
- **Comportamento de Pagamento:** Análise de share entre Pix, Cartão e Dinheiro.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3.10+
- **Bibliotecas:** Pandas (Dados), NumPy (Cálculo), Plotly (Visualização Interativa)
- **Ambiente:** Google Colab

## 🏃 Como Rodar
1. Baixe o arquivo `Analise_Varejo_Completa.ipynb`.
2. Abra no [Google Colab](https://colab.research.google.com/).
3. Execute a única célula de código. Tudo (geração, limpeza e gráficos) roda automaticamente sem necessidade de instalação local.
